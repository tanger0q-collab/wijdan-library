# Packaged Font Sources

These files are packaged so a clean Creative OS kit can render its verified families without depending on a previous page directory.

| File | Family | Recorded upstream | License record |
|---|---|---|---|
| `Alexandria.ttf` | Alexandria variable family | `https://fonts.google.com/specimen/Alexandria` | The canonical collection guide records the family as downloaded from the official Google Fonts repository under SIL Open Font License. |
| `ElMessiri.ttf` | El Messiri variable family | `https://fonts.google.com/specimen/El+Messiri` | The canonical collection guide records the family as downloaded from the official Google Fonts repository under SIL Open Font License. |

The upstream URLs and license must still be checked during a real client handoff. No other workspace font is packaged because its portable license/source record is incomplete or its role is project-specific.
